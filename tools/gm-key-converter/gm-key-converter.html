格式说明与开源组件

GM0016 固定使用小端序，仅 32 位整数字段按小端编码；GM0009 使用 ASN.1 DER。SM2 两种格式使用 SM4-ECB / NoPadding。RSA 仅输出现有项目兼容 Blob，使用 RSA PKCS#1 v1.5 + 3DES-CBC，算法标识 0x2002；不代表所有 SKF 厂商通用格式。

解封需要签名证书对应的私钥。支持 SM2 和 RSA 2048 / 3072 / 4096 位。本工具检查算法和加密密钥对匹配，不验证证书信任链、有效期或用途。清空会移除页面中的输入与结果；JavaScript 运行时不能保证字符串立即从内存中抹除。
