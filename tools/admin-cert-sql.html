UKey 管理员证书导入 SQL 生成工具

从 wekey-skf 枚举 UKey 并导出签名证书，生成 sms_admin / sms_admin_cert 的 PostgreSQL 导入 SQL（按 u_key_sn 存在则更新）
1连接 wekey-skf 并枚举设备
选择设备名称序列号 厂商标签固件版本已登录
2获取管理员签名证书
取容器中 certType=0 的签名证书；UKey 未导入证书时请使用下方手动粘贴
手动粘贴 PEM 证书（兜底）
主题 DN
通用名 CN
证书序列号
有效期
密钥类型
SHA-256 指纹
尚未载入证书
3填写管理员信息
role_id 需与目标库 sms_role 表中的 id 对应；管理员启用状态默认写入「启用」，授权有效期取证书到期时间。
4生成导入 SQL（PostgreSQL）
逻辑：按 u_key_sn 判断，sms_admin 存在则更新、不存在则插入；证书按 sn 同理；最后关联 sign_cert_id 并推进序列。
请在目标库执行前确认 BEGIN/COMMIT 事务完整提交。
