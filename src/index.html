CRYPTO & CERTIFICATE UTILITIES

常用密码工具，一个入口。

国密密钥转换、UKey 证书导入与 Jasypt 加解密。计算在浏览器内完成，输入不会发送到本站。

国密密钥格式转换

本地计算 · 无需联网

使用签名证书保护加密私钥，输出 GM0016（小端序）或 GM0009。支持证书 PEM / DER，以及未加密的 PKCS#8 / SEC1 PEM 私钥。

UKey 管理员证书 SQL

需要本地 UKey 服务

读取 UKey 签名证书，为现有 sms_admin / sms_admin_cert 表生成 PostgreSQL 导入脚本。本工具仅生成 SQL，执行前请确认目标库与角色 ID。

需要启动 wekey-skf 服务并插入 UKey。在线页面可能受到浏览器本地网络权限、跨域或混合内容限制；连接失败时，请下载离线版本地打开，并检查服务的 CORS 配置。手动粘贴证书仍需选择设备。

Jasypt 加密与解密

本地计算 · 无需联网

固定使用 PBEWithHMACSHA512AndAES_256 对应参数：PBKDF2-HMAC-SHA512、1000 次迭代、AES-256-CBC。支持手动处理和简单缩进结构 YAML 的 ENC(...) 批量解密。
